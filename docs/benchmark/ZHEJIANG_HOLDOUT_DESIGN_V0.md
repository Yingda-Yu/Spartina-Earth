## 1. 为什么不能随机切像元/瓦片

- 三湾潮滩互花米草群落沿堤线、潮沟连续分布，相邻斑块高度自相关；
- 同一地物在不同日期被反复成像；
- 既有标签存在跨产品同源问题（见 §5）。
随机切相邻瓦片会让同一群落、同一影像、甚至同一标签同时进训练与测试。

## 2. 分组单元（候选，待 M2.1b 用真实像元分布定参）

1. **空间单元**：沿海岸线的分段（coastal segment），以堤线/潮沟/
   岬角等自然断点为界，并在投影坐标（EPSG:32651）上加固定缓冲区
   （候选 500 m，TODO_VERIFY：用变异函数估计实际相关距离后再定）；
2. **时间单元**：同一地点跨日期的全部影像（及由其产出的全部标签/
   特征）属于同一 group，禁止跨年打散；
3. **层级**：scene → tile → segment → bay；分组在最高相关层级
   （segment；跨湾实验在 bay 层）进行。

## 4. 治理（管理措施）事件与 T1 的关系

互花米草防治（刈割、围淹、覆膜、生物替代、堤防工程）会让"同一位置
跨年份标签"发生真实的类别翻转。T1 设计要求：

- 治理事件发生年附近不得把前后像元当作标签噪声互相"纠正"；
- 事件发生后复发监测是旗舰科学问题的一部分，需独立分层；
- M2.1a 尚未找到可核验的三湾治理事件台账（见验收报告 §管理事件
  schema 盘点：全部 UNKNOWN），T1 的治理前后切分**暂缓**，待证据。

## 5. 既有标签在 split 中的限制（来自真实盘点）

依据 [ZHEJIANG_LABEL_INVENTORY_V0.md](../data/ZHEJIANG_LABEL_INVENTORY_V0.md)
的实测交集：

- L1（全国 2015 30 m，SILVER）：杭州湾 19,268 像元、乐清湾
  22,889 像元、三门湾 0；再分发受限，仅可作验证参考；
- L2（CM-SSM 2020，WEAK）：三湾实测交集全部为 0，不能进入任何
  split 的样本计数；
- L4/L5/L6（CMSA 2019/2020/2021，WEAK，来源 UNKNOWN）：仅乐清湾
  湾头有交集（51/158/79 个要素），三年产品空间范围几乎重叠，
  **同源/近重复风险高**：若用于乐清湾，三个年份必须整体落在同一
  group 同一侧，禁止跨年分两侧；
- L3（杭州湾 mask 2015，WEAK）：仅杭州湾 15,600 像元，且与 L1
  同年同地，禁止一边训练一边验证；
- GOLD = 0：在野外/UAV/专家验证证据入库前，任何 split 的指标都
  只能称为 SILVER/WEAK 参考指标；
- U1–U8 合成体：UNLABELED，仅可进入自监督预训练池；文件名含
  "Spartina" 不等于标签（U6/U8 字节级审计留 M2.1b）。

## 6. 本阶段明确不做

- 不生成 split 文件、不冻结任何缓冲距离与年份切点；
- 不在 R/T/S/M 任一命题上报告模型分数（没有实验，没有结果）；
- 不把 R1–M1 写成"论文级基准"——它们是待验证假设；
- split 冻结需要：segment 图层 + 相关距离证据 + 治理事件台账 +
  GOLD/SILVER 标签入库，全部是 M2.1b 或之后的前置条件。
