\section{Preliminary Pilot-0 baselines}\label{sec:baselines}

Pilot-0 is a deliberately small Hangzhou-2015 engineering exercise. Its
purpose is to exercise the label arbitration, co-registration, split,
and evaluation machinery before the corrected observation model
exists---not to estimate population accuracy.

\subsection{Label preparation}
The SILVER national raster and a WEAK local index-derived mask overlap
only partially: arbitration sampling records Jaccard 0.4929 (precision
0.633, recall 0.691) across the full overlap region, with disagreement
concentrated at boundaries and patch edges; on evaluable core pixels
after the documented boundary handling, agreement rises to Jaccard
0.953. Co-registration scans find zero best whole-pixel lag in every
evaluated pair (integer lag (0,0)); residual differences are sub-pixel
and are carried as registration uncertainty. The primary evaluation view
is \texttt{arbitrated\_core}; a \texttt{silver\_strict} view reports
SILVER-product reproduction separately so the two label sources are not
silently merged.

\subsection{Baseline ladder and what it does---and does not---establish}
Forty-nine official runs over a spectral-angle-index rule, Random
Forest with four input variants, U-Net, DeepLabV3+, and SegFormer-B0
were reconciled against frozen manifests and a final-evaluation lock;
the locked test set was evaluated exactly once (Table~\ref{tab:pilot0}).

\input{tables/tab_pilot0}

Three observations are defensible. First, all learned models beat the
rule-based baseline, and the strongest configuration (U-Net with
spectral indices) reaches mean core IoU 0.816. Second, added modalities
are not free: deep networks degrade under some full-input variants,
and missing-modality stress without retraining collapses several
configurations (e.g.\ U-Net dropping index channels falls to IoU
0.037), showing that apparent multimodal gains depend on fragile
channels. Third, SegFormer-B0 exhibits seed-level collapse, including
one run at exactly 0.000 IoU, which is reported per run rather than
averaged away; calibration error likewise varies widely.

None of these numbers is an accuracy claim about Spartina mapping. The
test set contains seven windows over five disconnected SILVER
components, so spatial block-level confidence intervals cannot be
estimated; three seeds cover initialization randomness only, not
geographic uncertainty. Responses over WEAK-only components are
reported strictly as candidate-response diagnostics because no GOLD
label exists for those pixels. The scientifically valid conclusions are
narrow: the pipeline trains, evaluates once, preserves provenance, and
surfaces failure modes; relative model ranking on this support is
suggestive only.
